Quick Start

Deploy in Minutes

Three commands to your first edge cloud cluster.

# Install dependencies on each node
sudo snap install microcloud lxd microceph microovn

# Initialize cluster (first node)
sudo microcloud init --bootstrap-max=3

# Join additional nodes
sudo microcloud init
